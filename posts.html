我怎么把这个网站搭起来的

发布于 2026-10-05 · 阅读约 2 分钟

这是一篇示例文章，用来告诉你文章页长什么样。你可以直接删掉这段文字，换成你自己写的东西。

我用的工具

没有电脑，所以我全程用手机上的编辑器写代码，改完直接推到 GitHub，网站会自动更新。

关于留言功能

留言用的是 Giscus，它把 GitHub 的 Discussions 当成数据库， 访客用 GitHub 账号登录就能评论，我一分钱都不用花，也不用自己写后端。

下一步想做的

先把文章写起来，等访问的人多了，再考虑换成自己的邮箱注册登录系统。
